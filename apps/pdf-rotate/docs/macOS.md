# PDF 旋转工具 · Mac

**v1.1.0 · by：linfeng365**

默认逆时针旋转 1°，可以输入小数角度，并单独选择“逆时针”或“顺时针”。

## 使用

1. 双击 `PDF旋转工具.app`。
2. 选择方向，在“角度”中填写数值，例如 `1`、`0.5`、`1.25`。
3. 将一个或多个 PDF 拖入窗口，或点“选择 PDF…”多选文件。
4. 处理完成后，点“显示结果”在 Finder 查看副本。

角度范围为 **0.001° 至 180°**。角度填写正数，方向通过下拉菜单选择。每次启动默认“逆时针 1°”；本批开始后方向与角度暂时锁定，完成后可以修改并继续处理。

也可以拖到应用图标或 Dock 图标上。应用尚未打开时，直接向图标拖入文件会使用默认逆时针 1°；需要其他角度时，请先打开窗口设置，再添加 PDF。

## 输出

输出位于每个原文件所在文件夹，文件名注明实际方向和角度：

```text
合同.pdf                       原件保留
合同_逆时针1度.pdf              默认设置
合同_顺时针0.5度.pdf            顺时针 0.5°
合同_顺时针0.5度_2.pdf          重名时自动编号
```

所有页面使用本批同一设置。多文件逐份处理，一份失败会报告原因并继续其余文件。

## 处理方式与环境

- 直接变换 PDF 内容坐标，不把页面转成图片，不重新压缩原扫描图片；正文和已有 OCR 文字层一起旋转。
- 略微扩大页面及可见边界以保留旋转后的四角，纸张尺寸会略增。
- 原有裁切区域外的隐藏内容继续保持隐藏。
- 适用于普通扫描 PDF；加密、数字签名、批注或表单文件会提示跳过，普通超链接可以保留。
- 再次处理输出副本会继续旋转所选角度。
- 界面底部与“关于 PDF 旋转工具”显示版本和 `by：linfeng365`。

为本机 Apple Silicon Mac 构建，使用本机已有的 `/usr/bin/python3`，内置 pypdf 6.10.0 及必要依赖；无需 pip 安装或联网。移动应用时，资源随 `.app` 一起移动。

本次已在 Mac 实际运行新版界面并处理自建测试 PDF，验证默认逆时针 1°、逆时针 0.5°、顺时针 1.25°、扫描图片数据、隐藏 OCR、原件保护和页面方向；另检查输入校验、重名编号及边界角度。旧版两端已由使用者反馈测试通过，新版 Windows 界面需单独复测。

`源码` 文件夹保留原生界面与处理引擎源码。命令行示例：

```bash
/usr/bin/python3 -B "/应用实际位置/PDF旋转工具.app/Contents/Resources/rotate_pdf.py" --angle 0.5 --direction cw "/资料/合同.pdf"
```

`cw` 为顺时针，`ccw` 为逆时针；省略参数即逆时针 1°。
